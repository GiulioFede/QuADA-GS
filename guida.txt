1) Clona il progetto sulla repository
    git clone https://github.com/GiulioFede/QuADA-GS.git

2) Per evitare problemi di percorsi, esegui dentro QuADA-GS (cartella principale)
    pip install -e .

3) crea ambiente conda
    conda create -n quadags python=3.11 -y
    (Installo PyTorch ottimizzato per le mie schede (CUDA 12.4))
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
    (installo altre dipendenze di progetto)
    pip install -r requirements.txt

4) Compilare rasterizzatore

    cd utils/gs_utils
    python setup_gscuda_adaptive.py install
